# Babylonian Bricks Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add sixteen decorative blocks — Babylonian bricks in four looks (regular, cracked, tiles, chiseled), each with stairs, slab and wall — obtained by mining the ruin and cut into every other form at a stonecutter.

**Architecture:** Two small Java classes plus registration; everything else is data. 133 JSON files are generated by Python scripts that read the *actual* vanilla 26.2 stone-brick equivalents out of the Minecraft jar and substitute ids, so no blockstate matrix or model shape is ever written from memory. Only the generated output is committed.

**Tech Stack:** Java 25, Minecraft 26.2 (official Mojang names, de-obfuscated), Architectury API 21.0.4, Architectury Loom (no-remap), Gradle. Python 3.13 + Pillow 11.2 for generation (developer-side only, never a build dependency).

**Spec:** `docs/superpowers/specs/2026-07-28-babylonian-bricks-design.md`

## Global Constraints

- **All logic lives in `common`.** Nothing in this plan touches `fabric/` or `neoforge/`.
- **Both loaders stay in lockstep.** A task is not done until `./gradlew build` succeeds — that one command builds both. It is green on `dev` as of this plan's writing, so a failure is yours.
- **MC 26.2 is de-obfuscated** — official Mojang names throughout. No Yarn/MCP/SRG.
- **Never assume API shapes from memory.** Every signature below was verified against `minecraft-merged-deobf-26.2.jar` with `javap`. If something does not compile, check the jar before changing the design.
- **`StairBlock`'s constructor is `protected`.** `new StairBlock(...)` will not compile from `common`. This is why `NabuStairBlock` exists. Do not delete it as redundant.
- **No test harness exists in this repo.** Per-task verification is `./gradlew build` plus the validator built in Task 3. Never claim in-world behaviour is verified — only that it compiles and validates. Jarno runs the game.
- **Generator scripts are NOT committed.** They live in the scratchpad. Only their output — JSON and PNG — enters the repo. This project has no datagen and hand-authored assets are its convention; committing a one-shot script would imply a pipeline that does not exist.
- **Committed JSON uses 2-space indent, LF newlines, and a trailing newline**, matching every existing file in the repo.
- Registration idiom: every block/item needs `.setId(Nabu.key(Registries.BLOCK|ITEM, "<name>"))`, and every item uses the private `tabbed()` helper in `NabuItems`.
- **Exact block ids** — these sixteen strings appear in ~130 files; a typo surfaces as missing-texture purple in-game, not as a build failure. Copy, never retype:

| Variant | Base | Stairs | Slab | Wall |
| --- | --- | --- | --- | --- |
| Regular | `babylonian_bricks` | `babylonian_brick_stairs` | `babylonian_brick_slab` | `babylonian_brick_wall` |
| Cracked | `cracked_babylonian_bricks` | `cracked_babylonian_brick_stairs` | `cracked_babylonian_brick_slab` | `cracked_babylonian_brick_wall` |
| Tiles | `babylonian_tiles` | `babylonian_tile_stairs` | `babylonian_tile_slab` | `babylonian_tile_wall` |
| Chiseled | `chiseled_babylonian_bricks` | `chiseled_babylonian_brick_stairs` | `chiseled_babylonian_brick_slab` | `chiseled_babylonian_brick_wall` |

import net.minecraft.world.level.block.StairBlock;
import net.minecraft.world.level.block.state.BlockBehaviour;

/**
 * A plain stair block with a public constructor.
 *
 * <p>{@link StairBlock}'s only constructor is {@code protected}. NeoForge patches it to public;
 * Fabric does not; {@code common} compiles against the vanilla signature either way, so

 *
 * <p>Adds no behaviour. {@code codec()} is deliberately not overridden -- it correctly inherits
 * {@code StairBlock.CODEC}, whose declared return type {@code MapCodec<? extends StairBlock>}
 * is covariant and so permits this subclass.
 */
public class NabuStairBlock extends StairBlock {
    public NabuStairBlock(BlockState baseState, BlockBehaviour.Properties properties) {
        super(baseState, properties);
    }
}

     * Registers one decorative variant: the base block plus its stairs, slab and wall.
     * The base is registered first so the stairs can read its default state.
     */
    private static BrickSet brickSet(String baseName, String formPrefix) {
        RegistrySupplier<Block> base = BLOCKS.register(
                baseName,
                () -> new Block(stoneLike(baseName)));

        return new BrickSet(
                baseName,
                formPrefix,
                base,
                BLOCKS.register(
                        formPrefix + "_stairs",
                        () -> new NabuStairBlock(
                                base.get().defaultBlockState(),
                                stoneLike(formPrefix + "_stairs"))),
                BLOCKS.register(
                        formPrefix + "_slab",
                        () -> new SlabBlock(stoneLike(formPrefix + "_slab"))),
                BLOCKS.register(
                        formPrefix + "_wall",
                        () -> new WallBlock(stoneLike(formPrefix + "_wall"))));
    }

    /** Stone-brick behaviour plus the per-block id that 26.x requires every block to carry. */
    private static BlockBehaviour.Properties stoneLike(String name) {
        return BlockBehaviour.Properties.ofLegacyCopy(Blocks.STONE_BRICKS)
                .setId(Nabu.key(Registries.BLOCK, name));

```python
"""Placeholder 16x16 textures for the Babylonian brick set.

Deterministic: a fixed RNG seed means re-running produces byte-identical files,
so regenerating never shows up as a spurious diff.
"""
import os
import random
from PIL import Image

RES = os.path.join("common", "src", "main", "resources")
OUT = os.path.join(RES, "assets", "nabu", "textures", "block")

N = 16
MORTAR = (122, 94, 62, 255)
BRICK = (176, 138, 90, 255)
LIGHT = (198, 162, 112, 255)
DARK = (140, 106, 68, 255)
CRACK = (92, 70, 46, 255)


def grain(rng, colour, spread=10):
    """Per-pixel jitter so flat fills do not look plastic."""
    d = rng.randint(-spread, spread)
    return (max(0, min(255, colour[0] + d)),
            max(0, min(255, colour[1] + d)),
            max(0, min(255, colour[2] + d)),
            255)


def courses(rng, offset_rows=True):
    """Running-bond brickwork: 4 courses of 4px, alternate courses offset by half a brick."""
    img = Image.new("RGBA", (N, N), MORTAR)
    px = img.load()
    for y in range(N):
        course = y // 4
        if y % 4 == 0:                      # horizontal mortar line
            continue
        shift = 4 if (offset_rows and course % 2) else 0
        for x in range(N):
            if (x + shift) % 8 == 0:        # vertical mortar line
                continue
            base = LIGHT if y % 4 == 1 else BRICK
            px[x, y] = grain(rng, base)
    return img


def tiles(rng):
    """Flush 8x8 grid -- no offset, which is what separates tiles from bricks at a glance."""
    img = Image.new("RGBA", (N, N), MORTAR)
    px = img.load()
    for y in range(N):
        if y % 8 == 0:
            continue
        for x in range(N):
            if x % 8 == 0:
                continue
            base = LIGHT if y % 8 == 1 else BRICK
            px[x, y] = grain(rng, base, 6)
    return img


def cracked(rng):
    """Brickwork plus fracture lines that ignore the mortar grid."""
    img = courses(rng)
    px = img.load()
    for _ in range(3):
        x, y = rng.randrange(N), rng.randrange(3)
        for _ in range(rng.randint(8, 13)):
            if not (0 <= x < N and 0 <= y < N):
                break
            px[x, y] = CRACK
            y += 1
            x += rng.choice((-1, 0, 0, 1))
    return img


def chiseled(rng):
    """A framed panel with a stepped ziggurat motif."""
    img = Image.new("RGBA", (N, N), BRICK)
    px = img.load()
    for y in range(N):
        for x in range(N):
            px[x, y] = grain(rng, BRICK, 6)
    for i in range(N):                       # border
        for p in ((i, 0), (i, N - 1), (0, i), (N - 1, i)):
            px[p] = MORTAR
    for i in range(1, N - 1):                # inner bevel highlight
        px[i, 1] = grain(rng, LIGHT, 4)
    steps = ((6, 11, 9), (5, 12, 8), (4, 13, 7), (3, 14, 6))   # (x0, x1, y)
    for x0, x1, y in steps:
        for x in range(x0, x1 + 1):
            px[x, y] = DARK
    return img


def main():
    os.makedirs(OUT, exist_ok=True)
    builders = {
        "babylonian_bricks": lambda r: courses(r),
        "cracked_babylonian_bricks": cracked,
        "babylonian_tiles": tiles,
        "chiseled_babylonian_bricks": chiseled,
    }
    for name, build in builders.items():
        img = build(random.Random(0xBABE1))
        img.save(os.path.join(OUT, name + ".png"))
        print("wrote", name + ".png")


if __name__ == "__main__":
    main()
```

```python
"""Shared helpers for generating the Babylonian brick set.

Nothing here writes Minecraft JSON from memory. Every file is produced by reading the
real vanilla stone-brick equivalent out of the 26.2 jar and substituting ids, so shapes
like the 40-variant stairs blockstate come out exactly right.
"""
import json
import os
import zipfile

MC_JAR = os.path.expanduser(
    "~/.gradle/caches/fabric-loom/minecraftMaven/net/minecraft/"
    "minecraft-merged-deobf/26.2/minecraft-merged-deobf-26.2.jar")

RES = os.path.join("common", "src", "main", "resources")

# (base name, form prefix). Two stems because the base is plural and the forms singular.
VARIANTS = [
    ("babylonian_bricks", "babylonian_brick"),
    ("cracked_babylonian_bricks", "cracked_babylonian_brick"),
    ("babylonian_tiles", "babylonian_tile"),
    ("chiseled_babylonian_bricks", "chiseled_babylonian_brick"),
]

FORMS = ("stairs", "slab", "wall")

# Longest first: "minecraft:" would otherwise swallow the more specific prefixes.
_PREFIXES = ("minecraft:block/", "minecraft:blocks/", "minecraft:item/", "minecraft:")


def all_block_names():
    """The sixteen ids, in creative-tab order."""
    names = []
    for base, prefix in VARIANTS:
        names.append(base)
        names.extend("{}_{}".format(prefix, f) for f in FORMS)
    return names


def map_id(s, base, prefix):
    """minecraft:…stone_bricks -> nabu:…<base>;  minecraft:…stone_brick_X -> nabu:…<prefix>_X"""
    if not isinstance(s, str):
        return s
    for p in _PREFIXES:
        if s.startswith(p):
            seg = p[len("minecraft:"):]          # "block/", "blocks/", "item/", ""
            rest = s[len(p):]
            if rest == "stone_bricks":
                return "nabu:" + seg + base
            if rest.startswith("stone_brick_"):
                return "nabu:" + seg + prefix + "_" + rest[len("stone_brick_"):]
            return s
    return s


def subst(obj, base, prefix):
    """Deep copy with every stone-brick id rewritten. Dict keys are never ids, so are left alone."""
    if isinstance(obj, dict):
        return {k: subst(v, base, prefix) for k, v in obj.items()}
    if isinstance(obj, list):
        return [subst(v, base, prefix) for v in obj]
    return map_id(obj, base, prefix)


def vanilla(path):
    with zipfile.ZipFile(MC_JAR) as z:
        return json.loads(z.read(path))


def write(relpath, obj):
    dest = os.path.join(RES, relpath)
    os.makedirs(os.path.dirname(dest), exist_ok=True)
    with open(dest, "w", encoding="utf-8", newline="\n") as f:
        json.dump(obj, f, indent=2, ensure_ascii=False)
        f.write("\n")
```

- [ ] **Step 4: Write the validator**

This is the gate for the rest of the plan. It catches the failure mode that the compiler cannot: a typo in a long repetitive id, which in-game shows up as purple, not as an error.

Create `$GEN/validate.py`:

```python
"""Cross-reference every generated file. Exits non-zero if anything fails to resolve.

Checks:
  1. Every JSON file under the mod's resource tree parses.
  2. Every nabu: model/texture reference resolves to a file that exists.
  3. Every minecraft: model/texture reference exists inside the 26.2 jar.
  4. Every bare nabu: id in a loot table, recipe or tag is a block/item we registered.

This script was run against the repo before any of this work and passes, so a failure is
something you introduced.
"""
import json
import os
import sys
import zipfile

sys.path.insert(0, os.path.dirname(os.path.abspath(__file__)))
import nabugen as g

# Blocks and items this mod registered before the brick set existed.
PREEXISTING = {
    "water_screw", "planting_bed", "garden_controller", "silphium", "silphium_seeds",
    "emmer", "emmer_seeds", "judean_date", "judean_date_seeds", "fertility_charm",
}
KNOWN = set(g.all_block_names()) | PREEXISTING


def ID_BEARING(rel):
    """Only these files carry bare block/item ids.

    Worldgen files also contain bare nabu: ids -- structures, template pools -- which are
    not blocks and must not be checked against the block list.
    """
    return (rel.startswith("data/nabu/loot_table/")
            or rel.startswith("data/nabu/recipe/")
            or "/tags/" in rel)


errors = []


def walk_strings(obj):
    if isinstance(obj, dict):
        for v in obj.values():
            yield from walk_strings(v)
    elif isinstance(obj, list):
        for v in obj:
            yield from walk_strings(v)
    elif isinstance(obj, str):
        yield obj


def main():
    with zipfile.ZipFile(g.MC_JAR) as z:
        jar = set(z.namelist())

    root = g.RES
    files = []
    for dirpath, _, names in os.walk(root):
        for name in names:
            if name.endswith(".json"):
                files.append(os.path.join(dirpath, name))

    for path in files:
        rel = os.path.relpath(path, root).replace(os.sep, "/")
        try:
            # utf-8-sig, not utf-8: the eight existing silphium_stage*.json models carry a
            # UTF-8 BOM. Minecraft's parser tolerates it, so this is not a bug to fix here.
            with open(path, encoding="utf-8-sig") as f:
                obj = json.load(f)
        except Exception as exc:                      # noqa: BLE001 - report, do not raise
            errors.append("%s: unparseable: %s" % (rel, exc))
            continue

        for s in walk_strings(obj):
            if s.startswith("nabu:block/") or s.startswith("nabu:item/"):
                kind, _, name = s.partition(":")[2].partition("/")
                # A model reference; a texture reference has no matching model file.
                model = os.path.join(root, "assets/nabu/models", kind, name + ".json")
                texture = os.path.join(root, "assets/nabu/textures", kind, name + ".png")
                if not os.path.exists(model) and not os.path.exists(texture):
                    errors.append("%s: dangling nabu ref %s" % (rel, s))
            elif s.startswith("minecraft:block/") or s.startswith("minecraft:item/"):
                kind = "block" if "block/" in s else "item"
                name = s.split("/", 1)[1]
                model = "assets/minecraft/models/%s/%s.json" % (kind, name)
                texture = "assets/minecraft/textures/%s/%s.png" % (kind, name)
                if model not in jar and texture not in jar:
                    errors.append("%s: vanilla ref not in jar: %s" % (rel, s))
            elif s.startswith("nabu:") and "/" not in s and ID_BEARING(rel):
                name = s.split(":", 1)[1]
                if name not in KNOWN:
                    errors.append("%s: unknown nabu id %s" % (rel, s))

    if errors:
        print("FAIL (%d):" % len(errors))
        for e in errors[:40]:
            print("  ", e)
        if len(errors) > 40:
            print("   … and %d more" % (len(errors) - 40))
        sys.exit(1)
    print("ok: %d json files, all references resolve" % len(files))


if __name__ == "__main__":
    main()
```

**Interfaces:**

- Produces: the complete recipe id list, which the advancement's `rewards.recipes` must match exactly.

**The recipe matrix:**

| Kind | Count | Detail |
| --- | --- | --- |
| Crafting | 12 | stairs 6→4, slab 3→6, wall 6→6, for each of the four variants |
| Crafting | 1 | `chiseled_babylonian_bricks` from two stacked `babylonian_brick_slab` |
| Smelting | 1 | `babylonian_bricks` → `cracked_babylonian_bricks`, 0.1 xp |
| Stonecutting | 11 | from `babylonian_bricks`: its own 3 forms, plus `babylonian_tiles` and `chiseled_babylonian_bricks` and all 3 forms of each |
| Stonecutting | 9 | from tiles / chiseled / cracked: each into its own 3 forms |

Cracked is reachable only through the furnace — no stonecutting path produces it, so smelting stays a deliberate step.

- [ ] **Step 1: Write the generator**

Create `$GEN/gen_recipes.py`:

```python
"""Recipes and the single recipe-unlock advancement for the Babylonian brick set."""
import sys
import os
sys.path.insert(0, os.path.dirname(os.path.abspath(__file__)))
import nabugen as g

BRICKS = "babylonian_bricks"
TILES = "babylonian_tiles"
CHISELED = "chiseled_babylonian_bricks"
CRACKED = "cracked_babylonian_bricks"

# base id -> form prefix
PREFIX = dict(g.VARIANTS)

# Stonecutting sources -> the base blocks they may also produce (beyond their own forms).
EXTRA_CUTS = {BRICKS: [TILES, CHISELED]}

written = []


def emit(name, obj):
    g.write("data/nabu/recipe/%s.json" % name, obj)
    written.append("nabu:" + name)


def crafting(src_template, ingredient, result_id, count=None):
    obj = g.vanilla("data/minecraft/recipe/%s.json" % src_template)
    obj["key"]["#"] = "nabu:" + ingredient
    obj["result"]["id"] = "nabu:" + result_id
    if count is not None:
        obj["result"]["count"] = count
    return obj


def stonecut(source, result_id, count):
    return {
        "type": "minecraft:stonecutting",
        "ingredient": "nabu:" + source,
        "result": {"count": count, "id": "nabu:" + result_id},
    }


def forms_of(base):
    p = PREFIX[base]
    return [("%s_stairs" % p, 1), ("%s_slab" % p, 2), ("%s_wall" % p, 1)]


def main():
    # --- crafting: stairs / slab / wall for every variant -------------------------------
    for base, prefix in g.VARIANTS:
        emit("%s_stairs" % prefix, crafting("stone_brick_stairs", base, "%s_stairs" % prefix))
        emit("%s_slab" % prefix, crafting("stone_brick_slab", base, "%s_slab" % prefix))
        emit("%s_wall" % prefix, crafting("stone_brick_wall", base, "%s_wall" % prefix))

    # --- crafting: chiseled from two stacked brick slabs --------------------------------
    emit(CHISELED, crafting("chiseled_stone_bricks", "babylonian_brick_slab", CHISELED))

    # --- smelting: the only route to cracked --------------------------------------------
    smelt = g.vanilla("data/minecraft/recipe/cracked_stone_bricks.json")
    smelt["ingredient"] = "nabu:" + BRICKS
    smelt["result"]["id"] = "nabu:" + CRACKED
    emit(CRACKED, smelt)

    # --- stonecutting --------------------------------------------------------------------
    for source in (BRICKS, TILES, CHISELED, CRACKED):
        targets = list(forms_of(source))
        for extra in EXTRA_CUTS.get(source, []):
            targets.append((extra, 1))
            targets.extend(forms_of(extra))
        for result_id, count in targets:
            emit("%s_from_%s_stonecutting" % (result_id, source),
                 stonecut(source, result_id, count))

    # --- one advancement unlocking every recipe at once ----------------------------------
    g.write("data/nabu/advancement/recipes/babylonian_bricks.json", {
        "parent": "minecraft:recipes/root",
        "criteria": {
            "has_babylonian_bricks": {
                "trigger": "minecraft:inventory_changed",
                "conditions": {"items": [{"items": "#nabu:babylonian_bricks"}]},
            }
        },
        "requirements": [["has_babylonian_bricks"]],
        "rewards": {"recipes": sorted(written)},
    })

    print("wrote", len(written), "recipes + 1 advancement")


if __name__ == "__main__":
    main()
```

## Notes for the reviewer

- **Task 1 is the only task that can fail to compile.** Tasks 3–5 produce data; their failure mode is silent (purple blocks, absent recipes), which is why each has an explicit cross-reference check rather than relying on the build.
- **`validate.py` is proven to fail before it is trusted** (Task 3, Step 5). A gate that has never been seen to fail is not a gate.
- **The generators read vanilla JSON rather than emitting it from memory.** If a check in Task 3 Step 8 reports something other than 40 stairs variants or 9 wall multipart entries, the substitution is wrong — do not hand-edit the output, fix `map_id` and regenerate.
- **Every "Expected:" value in this plan was produced by actually running the command**, against either the repo or the 26.2 jar — including the 40/9 counts, the file totals, and the validator's `ok: 73` baseline. They are observations, not predictions.

### One pre-existing quirk found while writing this plan

The eight `assets/nabu/models/block/silphium_stage*.json` files carry a **UTF-8 BOM**. Minecraft's JSON parser tolerates it and the game loads them fine, so this is not a bug and fixing it is out of scope for this work — but it is why `validate.py` reads with `utf-8-sig`. Worth knowing if Jarno ever hits a tool that is stricter. Files generated by this plan are written BOM-free.
